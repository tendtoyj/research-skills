# market-scanner · 시장 스캔 (동향 + 규모)

주제가 속한 시장이 **어떤 흐름 속에 있고(PEST), 얼마나 큰지(TAM·SAM·SOM)** 조사한다. 규모는 숫자 하나보다 **어떻게 계산했는지**를 남기는 것이 목표다. 결과 파일은 다른 조사와 종합 단계가 공통으로 읽는 바탕이 된다.

## 공통 규칙

- **참고 자료**: 작업 공간(대화 첨부, 프로젝트 파일, 지시문)에 맥락 파일이나 리서치 가이드가 있으면 먼저 읽는다. 그 안의 용어 정의, 데이터 소스, 해석 시 주의점, 체크리스트를 이 스킬의 기준보다 우선한다.
- **출처**: 모든 수치와 주장에 [기관명, 자료명, 데이터 연도, 링크]를 붙인다. 검색 결과 요약만 보고 쓰지 않고 원문을 열어 수치가 거기 있는지 확인한다. 찾지 못하면 "확인 필요"라고 쓰고 추측으로 채우지 않는다.
- **최신성**: 검색어에 연도를 넣는다. 3년 넘은 자료는 쓰지 않거나 "(YYYY년 기준)"을 붙인다. 제도·규제는 시행일과 최신 개정 여부를 확인한다.
- **결과는 파일로**: 대화창 답변이 아니라 **다운로드할 수 있는 파일 두 개**를 처음부터 함께 만든다. 원본 `market-landscape.md`와 보기용 `market-landscape.html`(아래 "보기용 HTML"). 사용자가 원하면 Word나 PDF도 준다. 사용자가 정한 파일명 규칙이 있으면 그것을 따른다.
- **메모리**: 본문은 저장하지 않는다. `[시장 스캔 완료] TAM / SAM / SOM · 가장 큰 기회 1줄`만 남긴다.
- **읽히는 문장으로 쓰기**: 결과(md와 html 모두)는 이 조사를 처음 보는 사람이 읽고 바로 이해할 수 있게 쓴다.
  - 항목마다 **무엇이 일어나고 있는지 → 근거 → 그래서 우리 주제에 무슨 뜻인지**를 완전한 문장("~다")으로 쓴다.
  - 단어, 화살표(→), 가운뎃점(·)만 이어 붙인 메모체로 쓰지 않는다. 화살표는 순서나 흐름을 보여 줄 때만 쓴다.
  - "한 줄"로 쓰라는 곳도 완전한 한 문장으로 쓴다. 표 칸에 다 못 쓰면 표 아래에 번호를 달아 문장으로 풀어 쓴다.
  - 줄임말과 전문 용어(TAM, SAM, SOM, CAGR, PEST 등)는 처음 나올 때 한 번 풀어 쓴다.
  - 예: (X) "외식 물가 상승 → 기회 · 곧" / (O) "외식 물가가 최근 3년 동안 약 11% 올랐다[통계청, 2025]. 점심값 부담이 커질수록 가격이 정해진 구독이 매력적으로 보일 수 있어, 우리 주제에는 1~3년 안에 기회가 된다."
- **분량**: 쪽수를 줄이려고 문장을 깎지 않는다. 맨 위 '한눈에 보기'만 읽어도 결론을 알 수 있게 하고, 본문은 이해에 필요한 만큼 문장으로 쓴다. 같은 내용을 되풀이하지 않는다.

## 먼저 읽을 것

시작하기 전에 작업 공간의 조사 파일을 모두 읽는다(`competitive-intel.md`, `customer-voice.md` 등).

- 이미 조사된 내용은 다시 조사하지 않고 이어서 본다.
- 다른 파일과 시장 정의가 다르면 사용자에게 알리고 어느 쪽으로 맞출지 묻는다.
- `market-landscape.md`가 이미 있으면 보완 모드를 제안한다.

## 1. 입력 확인

아래가 대화, 지시문, 메모리에 없으면 한 번에 묻는다. 이미 있으면 확인만 하고 넘어간다. 주제 정의가 아예 없으면 `/research-topic`으로 먼저 정하자고 안내한다.

| 항목 | 필수 | 설명 |
|---|---|---|
| 리서치 주제 정의 | 예 | [누가] [어떤 상황에서] [어떤 불편]을 겪는가 |
| 리서치 시장 정의 | 예 | 없으면 2단계에서 같이 정한다 |
| 서비스 형태와 가격 가정 | 아니요 | 모르면 "월 구독 / 1회 구매 / 기업·기관 판매" 중 하나를 가정하고 "가정"으로 표시한다 |
| 지역 범위 | 아니요 | 기본은 국내. 해외 비교가 필요하면 국가를 받는다 |
| 이미 아는 자료 | 아니요 | 사용자가 가진 기사, 보고서, 링크 |
| 조사 깊이 | 아니요 | 가볍게 / 보통 / 깊게 (기본: 보통) |

## 조사 깊이

| 깊이 | 단계당 웹 검색 | 원문 열람 | PEST 칸당 항목 | 규모 리포트 비교 | 시장 구조 축 |
|---|---|---|---|---|---|
| 가볍게 | 1~2회 | 0~1건 | 1~2개 | 1개 | 2개 |
| 보통 | 3~4회 | 2~3건 | 2~3개 | 2개 | 3개 |
| 깊게 | 5~6회 | 4~6건 | 3개 | 3개 이상 | 4개 |

"빠르게", "간단히"는 가볍게, "자세히", "제대로"는 깊게로 본다.

## 2. 시장 정의

조사를 시작하기 전에 시장을 좁게 정의한다. 넓은 업종("교육", "푸드")이 아니라 "수도권 사무실 직장인 대상 점심 식사 정기 구독 시장"처럼 쓴다.

- 시장 이름과 범위
- **경계**: 들어가는 것과 들어가지 않는 것
- **인접 시장**: 일부 겹치는 시장 (간접 경쟁사가 나오는 곳)
- 이용자 / 결정자 / 지불자가 각각 누구인지 (쓰는 사람, 도입을 결정하는 사람, 돈을 내는 사람)
- 참고 자료에 시장을 나누는 기준(예: 규제 대상인지 아닌지)이 있으면 여기서 판단하고, 애매하면 "경계, 확인 필요"

## 3. 시장 동향 (PEST)

웹 검색으로 자료를 찾는다. 찾는 순서는 검색엔진 → 공공 통계·기관 자료 → 전문·학술 자료다. 커뮤니티 반응은 사회(S) 항목의 가설로만 쓴다. 참고 자료에 추천 데이터 소스가 있으면 그것부터 본다.

| 칸 | 볼 것 |
|---|---|
| P 정치·법 | 규제, 인허가, 제도 변화, 개인정보 규제, 광고 규제, 정부 지원 사업 |
| E 경제 | 소비 여력, 가격과 지불 의향, 지불 주체, 투자 흐름, 비용 구조 |
| S 사회 | 인구 변화, 생활 방식, 인식과 정보 이용 행태, 접근성 |
| T 기술 | 새 기술, 확산 속도, 데이터 연동, 대체 기술 |

항목마다 다음을 적는다.

- 무엇이 일어나고 있나 (한두 문장)
- 우리 주제에 **기회**인가 **위협**인가
- 시점: 지금(0~1년) / 곧(1~3년) / 장기(3~5년)
- 근거: 수치나 사례 + 출처

## 4. 시장 규모 (TAM / SAM / SOM)

### 정의부터 맞추기

| 단계 | 뜻 | 예 |
|---|---|---|
| TAM 전체 시장 | 이 문제를 가진 사람 전체가 쓸 수 있는 시장 | 수도권 사무직 직장인 전체의 점심 식비 |
| SAM 유효 시장 | 우리 서비스 형태로 실제 닿을 수 있는 시장 | 그중 정기 배송을 받을 수 있는 사무실 밀집 지역 직장인 |
| SOM 수익 시장 | 3년 안에 현실적으로 가져올 수 있는 몫 | SAM 중 초기 채널로 확보 가능한 비율 |

지불자가 이용자와 다르면(회사, 기관, 보험, 부모가 돈을 냄) **누구 기준으로 셀지** 먼저 정한다. 이용자 수 기준 시장과 지불자 매출 기준 시장을 섞지 않는다.

### 위에서 아래로 (Top-down)

리포트에 나온 시장 규모에서 출발해 좁혀 간다.

- 시장 규모 리포트를 깊이에 맞게 찾는다. 기관마다 시장 정의가 다르니 **범위**로 적는다. 자료가 서로 다르면 차이와 이유를 쓴다.
- 각 리포트의 시장 정의, 데이터 연도, 성장률(CAGR)과 기간을 함께 적는다.

### 아래에서 위로 (Bottom-up)

사람 수 × 비율 × 가격으로 직접 계산한다. 계산 과정이 드러나서 검증하기 쉬우므로 이쪽을 더 중요하게 본다.

```
대상 인구 (공공 통계)
× 문제를 겪는 비율 (조사·통계)
× 서비스로 닿을 수 있는 비율 (이용률, 지역, 채널)
× 1인당 연간 지출 (가격 가정)
= 시장 규모
```

- 단계마다 숫자, 출처, 데이터 연도를 적는다.
- **조사 추정치와 실제 이용·거래 기록**처럼 성격이 다른 숫자를 섞지 않는다. 어느 쪽을 썼는지 적는다. 참고 자료에 이런 구분이 있으면 그 기준을 따른다.
- 출처 없이 넣은 비율은 "가정"으로 표시한다.
- 인구·지역 분모는 공공 통계표에서 직접 다시 확인해 보라고 사용자에게 안내한다.

### 시나리오

핵심 가정(닿는 비율, 가격)을 바꿔 보수 / 기준 / 낙관 세 값을 낸다. 어느 가정이 결과를 가장 크게 바꾸는지 한 줄로 적는다.

## 5. 시장 구조와 수요 주기

시장이 어떻게 나뉘어 있는지 깊이에 맞는 축 수만큼 본다.

- 가격대: 저가 / 중간 / 고가
- 채널: 온라인 직접 판매, 앱 마켓, 오프라인, 기업·기관 판매 등
- 고객군: 누가 사나 (상황, 개인·기업)
- 하위 카테고리: 주요 제품·서비스 종류

수요 주기도 본다. 많이 찾는 때와 적게 찾는 때, 행사·제도 일정에 따른 변화. 뚜렷한 주기가 없으면 "뚜렷한 주기 없음"이라고 쓴다.

## 6. 시사점

동향과 규모를 함께 놓고 우리 주제에 중요한 시사점 3개를 뽑는다. 각 시사점에 근거가 된 항목 번호(PEST 번호, 규모 표)를 단다.

## 보기용 HTML

md와 같은 내용을 **도식으로 바꿔** 한눈에 보이게 한 `market-landscape.html`을 처음부터 함께 만든다. md의 표를 HTML 표로 옮기는 것이 아니다. 분석 하나마다 아래 정한 도식 하나로 그린다.

- **md가 원본**: 다음 단계와 검토에는 md를 쓴다. HTML에만 있는 내용을 넣지 않고, md를 고치면 HTML도 고친다. 보완 모드에서는 둘 다 `-v2`로 만든다.
- **표는 맨 아래에만**: 위쪽 도식 부분에는 `<table>`을 쓰지 않는다. 도식은 CSS 격자(grid·flex)와 인라인 SVG로 그린다. 표는 맨 아래 "자세히 보기"(`<details>`로 접어 둠)에만 둔다.
- **파일 하나로 완결**: CSS는 `<style>` 안에 넣는다. 외부 스크립트·웹 폰트·이미지 링크를 쓰지 않는다. 흰 배경, 본문 최대 너비 960px, 휴대폰에서는 2열·4열 도식을 1열로 접는다. A4로 인쇄해도 잘리지 않게 한다.
- **근거 표시 유지**: 출처 번호, "확인 필요", "가정"을 도식 안에 작은 배지로 남긴다. "가정"인 칸은 점선 테두리로 그린다.
- **참고 자료**에 시각화 기준(색, 양식)이 있으면 그것을 따른다.

**이 화면의 질문**: 이 시장은 크고, 지금 커지고 있나?

**도식** (위에서 아래 순서)

1. **한눈에 보기**: 카드 5장 가로 배열. 시장 정의 / TAM·SAM·SOM / 가장 큰 기회(초록 ▲) / 가장 큰 위협(빨강 ▼) / 가장 민감한 가정(점선).
2. **시장 경계 과녁** (md "시장 정의"): 가운데 원 = 우리 시장 이름과 들어가는 것. 바깥 고리 = 인접 시장 2~3개를 고리 위 칩으로. 원 밖 회색 글씨 = 들어가지 않는 것. 그 아래 이용자 → 결정자 → 지불자를 사람 아이콘 3개와 화살표로. 같은 사람이면 하나로 합친다.
3. **PEST 2×2** (md "시장 동향"): 왼쪽 위 P, 오른쪽 위 E, 왼쪽 아래 S, 오른쪽 아래 T. 칸마다 색을 다르게 한다(P 남색 `#2f4b7c`, E 초록 `#2e7d4f`, S 주황 `#c8702a`, T 보라 `#6b4fa0`, 칸 배경은 그 색의 아주 연한 색). 칸 안 항목은 카드 한 장씩: 왼쪽에 기회 ▲(초록)·위협 ▼(빨강), 오른쪽 위에 시점 배지(지금 / 곧 / 장기), 본문은 한 줄 요약, 아래에 번호(P1)와 출처 배지. 가장 큰 기회·위협 카드는 굵은 테두리.
4. **TAM·SAM·SOM 동심원** (md "시장 규모"): 인라인 SVG 원 세 개, 바깥부터 연한 색 → 진한 색. 원마다 이름, 금액, 한 줄 정의, 신뢰도 배지(높음·중간·낮음). 위에 "셀 기준: 이용자 수 / 지불자 매출" 배지. 원 크기는 실제 비율에 맞추지 않아도 된다. 성장률은 옆에 화살표 숫자로.
5. **Bottom-up 깔때기** (md "Bottom-up: 계산"): 대상 인구 → × 문제를 겪는 비율 → × 닿을 수 있는 비율 → × 1인당 연간 지출 → = 결과. 위에서 아래로 좁아지는 띠 5단. 단마다 값과 출처 배지. 출처 없는 단은 점선 + "가정".
6. **시나리오 막대** (md "시나리오"): 보수 / 기준 / 낙관 SOM을 가로 막대 3개로. 막대 끝에 금액, 옆에 핵심 가정 한 줄. 막대 아래 강조 상자에 "결과를 가장 크게 바꾸는 가정".
7. **시장 구조 띠와 수요 달력** (md "시장 구조와 수요 주기"): 축(가격대, 채널 등)마다 가로 띠 하나를 구간으로 나누고, 우리 주제가 들어갈 구간에 핀. 수요 주기는 1~12월 칸 12개, 많이 찾는 달을 진하게. 주기가 없으면 "뚜렷한 주기 없음" 한 줄.
8. **시사점 카드 3장** (md "시사점"): 카드마다 한 문장, 아래에 근거 배지(P1, SAM). 배지 색은 PEST 색과 맞춘다.

**자세히 보기 (표)**: PEST 전체 표, Top-down 리포트 비교, Bottom-up 계산 표, 확인 필요 목록, 출처, 조사 기록.

**가장 강조할 것**: SOM 숫자와 그 계산식.

**조심할 것**
- 출처가 다른 리포트 숫자를 한 그래프에 섞지 않는다. 리포트 비교는 "자세히 보기" 표로 둔다.
- 계산으로 낸 숫자에는 "추정" 배지를 단다.

## 품질 체크리스트

- [ ] 메모체(단어·화살표만 이은 줄) 없이 완전한 문장으로 썼고, 항목마다 "그래서 무슨 뜻인지"가 있다
- [ ] md와 html을 둘 다 만들었고, 두 파일의 내용이 같다
- [ ] html 위쪽에 표가 없고, "보기용 HTML"에 정한 도식이 모두 그려졌다
파일을 내기 전에 확인한다.

- [ ] 시장 정의가 좁혀져 있고, 들어가는 것과 들어가지 않는 것이 있다
- [ ] 이용자 / 결정자 / 지불자를 구분했다
- [ ] PEST 항목마다 기회·위협, 시점, 근거가 있다
- [ ] 규모에 Top-down과 Bottom-up이 모두 있고, Bottom-up 단계마다 출처나 "가정"이 있다
- [ ] 이용자 기준과 지불자 기준을 섞지 않았다
- [ ] 시나리오와 가장 민감한 가정이 있다
- [ ] 시장 구조를 깊이에 맞는 축 수만큼 채웠고, 수요 주기가 비어 있지 않다
- [ ] 원문을 열어 확인하지 못한 수치는 "확인 필요"로 표시했다
- [ ] 참고 자료가 있었다면 그 기준(용어, 주의점)을 지켰다

## 예시 (일부)

입력: 주제 "출근일이 들쭉날쭉한 30대 1인 가구 직장인이 점심 메뉴 고르기가 피곤하고 점심값이 부담된다"

> **시장 정의**: 이 조사의 시장은 수도권 사무실에 다니는 직장인이 점심을 정기 구독으로 받는 시장이다. 배달앱으로 그때그때 시키는 단건 주문과 회사 구내식당은 같은 문제를 다른 방식으로 푸는 인접 시장으로 보고 규모 계산에서 뺐다.
>
> **PEST · E1 경제 (기회, 지금)**: 외식 물가가 최근 3년 동안 약 11% 올랐다[통계청, 2025]. 점심값이 부담될수록 한 달 가격이 정해진 구독이 "덜 신경 쓰이는 선택"으로 보일 수 있어, 지금 바로 기회가 된다.
>
> **PEST · S1 사회 (기회, 1~3년)**: 출근과 재택을 섞어 일하는 회사가 늘고 있다[고용 조사, 2025]. 매일 배송되는 기존 구독은 재택하는 날 음식이 남는 문제가 생기므로, 출근일에 맞춘 구독이 들어갈 자리가 생긴다.
>
> **SAM (유효 시장: 우리 서비스로 실제 닿을 수 있는 시장)**: 수도권 사무직 OO만 명 가운데 주 3회 이상 점심을 사 먹는 사람이 OO%, 그중 정기 배송이 가능한 지역에 있는 사람이 OO%라고 보면, 1인당 연 OO원을 쓸 때 연 OO억 원 규모다.
>
> **가장 민감한 가정**: 정기 배송이 가능한 지역의 비율이다. 이 값이 절반으로 줄면 SAM도 절반이 되므로, 검증할 때 가장 먼저 확인해야 한다.
