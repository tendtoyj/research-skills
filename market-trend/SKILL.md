# market-trend · 시장 동향 조사 (PEST)

시장조사 1단계다. 주제가 속한 시장이 어떤 흐름 속에 있는지 PEST 틀로 정리한다. 이 결과는 시장 규모(market-size), 경쟁사 분석(competitor-analysis), STP(stp-canvas)가 이어서 읽는다.

## 공통 규칙

- **맥락 파일**: 시작 전에 프로젝트 파일의 `healthcare-context.md`를 읽고 그 기준을 따른다. 파일이 없으면 사용자에게 "프로젝트 파일에 healthcare-context.md를 올려 주세요"라고 알리고, 올리지 않겠다고 하면 그대로 진행하되 결과 맨 위에 "맥락 파일 없이 작성"이라고 적는다.
- **출처**: 모든 수치와 주장에 [기관명, 자료명, 데이터 연도, 링크]를 붙인다. 찾지 못하면 "확인 필요"라고 쓴다. 추측으로 채우지 않는다.
- **결과는 파일로**: 결과는 대화창 답변이 아니라 **다운로드할 수 있는 파일**로 만든다. 형식은 `.md`가 기본이고, 사용자가 Word나 PDF를 원하면 그 형식으로 만든다. 파일명은 `market-trend.md`이다. 프로젝트 지시문에 파일명 규칙이 있으면 그 규칙을 따른다.
- **메모리**: 결과 본문을 메모리에 저장하지 않는다. 메모리에는 `[트렌드 완료] 주제 / 핵심 수치 3개`만 한 줄로 남긴다.
- **분량**: A4 2~3쪽 안쪽. 표를 우선 쓰고 문장은 짧게.

## 1. 입력 확인

아래가 대화나 메모리에 없으면 한 번에 묻는다. 이미 있으면 확인만 하고 넘어간다.

| 항목 | 필수 | 예 |
|---|---|---|
| 주제 | 예 | 성인 당뇨병 환자가 진료 전 혈당 기록을 정리하기 어렵다 |
| 지역 범위 | 아니요 | 기본값은 한국. 해외 비교가 필요하면 국가를 받는다 |
| 이미 아는 자료 | 아니요 | 사용자가 가진 기사, 보고서, 링크 |

주제는 메모리에 한 줄로 남겨서 다음 스킬이 다시 묻지 않게 한다.

## 2. 시장 정의

조사를 시작하기 전에 시장을 좁게 정의한다. "헬스케어"가 아니라 "성인 2형 당뇨 환자용 자가 혈당 관리 앱 시장"처럼 쓴다.

- 시장 이름과 범위 (무엇이 들어가고 무엇이 빠지는지)
- **의료인가 웰니스인가** (맥락 파일 1장 기준). 애매하면 "경계, 확인 필요"
- 이용자 / 결정자 / 지불자가 각각 누구인지 (맥락 파일 2장 기준)

## 3. PEST 조사

웹 검색으로 자료를 찾는다. 찾는 순서는 검색엔진 → 공공 통계·기관 자료 → 전문·학술자료다. 커뮤니티 반응은 사회(S) 항목의 가설로만 쓴다.

각 칸에 2~3개 항목을 찾는다. 헬스케어에서 특히 볼 것:

| 칸 | 헬스케어에서 볼 것 |
|---|---|
| P 정치·법 | 의료기기·디지털의료제품 규제, 비대면진료 제도, 개인정보(민감정보) 규제, 의료광고 규제, 정부 지원 사업 |
| E 경제 | 건강보험 급여·수가, 지불 주체, 의료비 추이, 투자 동향, 가격 지불 의향 |
| S 사회 | 고령화, 만성질환 증가, 1인 가구, 건강정보 이용 행태, 의료 접근성 |
| T 기술 | AI, 웨어러블·센서, 데이터 연동(마이데이터·EMR), 원격 모니터링 |

항목마다 다음을 적는다.

- 무엇이 일어나고 있나 (한두 문장)
- 우리 주제에 **기회**인가 **위협**인가
- 시점: 지금(0~1년) / 곧(1~3년) / 장기(3~5년)
- 근거: 수치나 사례 + 출처

규제와 제도는 시행일과 최신 개정 여부를 확인한다. 확인하지 못하면 "시행 시점 확인 필요"라고 쓴다.

## 4. 시사점

PEST를 바탕으로 우리 주제에 중요한 시사점 3개를 뽑는다. 각 시사점에 근거가 된 PEST 항목 번호를 단다.

## 6. 마무리

파일을 만든 뒤 사용자에게 세 줄로 알린다.

1. 파일 이름과 다운로드 위치
2. "다운로드해서 프로젝트 파일에 올려 주세요. 다음 단계가 이 파일을 읽습니다."
3. 확인 필요 항목 개수 (팩트체크 단계에서 볼 것)

## 업데이트 모드

사용자가 이전 트렌드 파일이나 팩트체크 결과를 주며 고쳐 달라고 하면, 처음부터 다시 쓰지 않고 바뀐 항목만 고친다. 파일명을 `market-trend-v2.md`로 하고, 맨 아래에 "수정 내역" 표(항목, 바꾸기 전, 바꾼 후, 근거)를 추가한다.

## 하지 않는 것

- 시장 규모 숫자 계산 → market-size
- 경쟁사 비교 → competitor-analysis
- 타겟 결정, 전략 제안 → stp-canvas
