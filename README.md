# research-skills

헬스케어 서비스 시장조사를 단계별로 진행하는 스킬 모음입니다. 각 폴더에 `SKILL.md`가 하나씩 들어 있습니다.

| 스킬 | 하는 일 | 기본 결과 파일 |
|---|---|---|
| [market-trend](market-trend/SKILL.md) | 시장을 정의하고 PEST(정치·법, 경제, 사회, 기술)로 동향을 정리합니다. | `market-trend.md` |
| [market-size](market-size/SKILL.md) | TAM·SAM·SOM을 리서치 리포트 비교와 직접 계산 두 방향으로 추정합니다. | `market-size.md` |
| [competitor-analysis](competitor-analysis/SKILL.md) | 직접·간접 경쟁사와 대체재를 찾아 3C와 SWOT으로 비교합니다. | `competitive-intel.md` |
| [stp-canvas](stp-canvas/SKILL.md) | 앞 단계 결과를 종합해 STP, 페르소나, 비즈니스 모델 캔버스를 만듭니다. | `strategy-brief.md` |
| [final-report](final-report/SKILL.md) | 모든 결과를 모아 발표용 PPT로 정리합니다. | `final-report` |

## 순서

`market-trend` → `market-size` → `competitor-analysis` → (검증) → `stp-canvas` → (검토) → `final-report`

앞의 세 스킬은 서로 독립적으로 실행할 수 있고, `stp-canvas`와 `final-report`는 앞 단계 결과 파일을 읽어 종합합니다.

## 공통 원칙

- 모든 수치와 주장에 출처를 붙이고, 확인하지 못한 내용은 "확인 필요"로 표시합니다.
- 결과는 파일로 만들고, 수정할 때는 `-v2` 보완본과 수정 내역을 남깁니다.
- 헬스케어 기준을 담은 참고 파일(`healthcare-context.md`)이 있으면 함께 읽습니다.
